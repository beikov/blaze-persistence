We are happy to announce the nineteenth bug fix release of the 1.6 series.

=== Hibernate ORM 7.3 and 7.4 support

It took some time, but the `blaze-persistence-integration-hibernate-7.2` artifact was finally updated in a way to support Hibernate ORM 7.3 and 7.4.

Since Wildfly 40/41 and Quarkus 3.36 use Hibernate ORM 7.3/7.4, this release enables the update to the latest Wildfly versions.
